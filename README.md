# Touchstone Projects

This repository collects the Touchstone projects. Each project is kept in its own folder so its pages, assets, and project-specific documentation stay together.

## Projects

### [Touchstone Task 2](./touchstonetask2/)

A static HTML website for Second Chance Animal Rescue. The project includes pages about the rescue, its services, and how to get involved.

To view it, open [`touchstonetask2/index.html`](./touchstonetask2/index.html) in a web browser. No build tools or dependencies are required. See the [project README](./touchstonetask2/README.md) for details.

## Repository structure

```text
touchstonetask2/    Touchstone Task 2 website and assets
```

Future Touchstone projects can be added as separate top-level folders and listed here.
