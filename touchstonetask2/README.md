# Touchstone Task 2

A static website for **Second Chance Animal Rescue**, built with HTML. It introduces the rescue, its mission, and ways to adopt, foster, volunteer, or donate.

## View the website

Open `index.html` in a web browser. No build tools or dependencies are required.

## Pages

- `index.html` — Home, mission, impact, featured animals, and ways to help
- `services.html` — Adoption, fostering, and volunteering
- `about.html` — About the rescue
- `contact.html` — Contact and getting involved

## Assets

Images are stored in `images/`. The home page also references `media/rescue-message_c.mp4`. MP4 files are excluded by this folder's `.gitignore`, so the video is not included in the repository. Add the video locally at that path if you want it to appear on the page.
